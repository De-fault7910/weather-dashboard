WeatherNow

A responsive React app using TailwindCSS to fetch and display real-time weather from OpenWeatherMap.

Features: Search cities, view temperature, humidity, wind speed, and weather icons. Handles errors and shows a loading state.

Setup: Clone repo, run npm install, add .env with VITE_OPENWEATHER_API_KEY=YOUR_KEY, then npm run dev.

Components: Navbar, SearchBar, WeatherCard, Loader, ErrorMessage, Footer.

Technologies: React JS, TailwindCSS, Vite, OpenWeatherMap API.

Stretch Goals: Weekly forecast, theme toggle, recent searches, geolocation.

Challenges: Async API calls, state management, responsive UI design.
